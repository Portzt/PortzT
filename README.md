---

## What I'm building

- **[podman-quadlet-containers](https://github.com/Portzt/podman-quadlet-containers)** —
  Rootless Podman containers on RHEL 9, defined as Quadlet units and deployed with Ansible.
  How I run all of my self-hosted services.

- **[kvm_provision](https://github.com/Portzt/kvm_provision)** —
  An Ansible role for provisioning KVM virtual machines on RHEL 9 with libvirt —
  cloud-image based, idempotent, and inventory-driven.

- **[ansible](https://github.com/Portzt/ansible)** —
  Playbooks and roles for managing my RHEL-based infrastructure, including execution
  environment builds with ansible-builder v3.

- **[bash](https://github.com/Portzt/bash)** —
  A curated collection of shell scripts for administration and automation tasks.
